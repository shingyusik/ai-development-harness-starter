# Harness Changelog

## 2026-05-24

### Added

- Generic starter README, agent routing map, license, ignore rules, PR template, and docs harness workflow.
- Generic harness bootstrap, config manifest, decision records, planning examples, policies, gates, roles, and templates.
- Starter validation scripts for docs, planning graph, harness contract, and documentation policy.

### Changed

- Harness guidance is project-neutral and customizable.
- Required checks are limited to starter harness checks until an adopting project adds its own commands.

### Removed

- Project-specific application, infrastructure, vendor, local path, and private workflow assumptions.
